# Support

## Questions and usage help

Read the [README](README.md), [operations guide](docs/OPERATIONS.md), and
[project status](docs/PROJECT_STATUS.md) first. If the answer is not covered,
open an issue with a minimal description of the goal, operating system, Node.js
version, and the relevant safe configuration fields.

## Bug reports

Use the bug report template and include a minimal reproduction. Sanitize all
diagnostics before posting. Do not attach tokens, private repository content,
personal messages, machine-specific paths, memory records, screenshots from a
real workspace, logs, backups, or generated validation artifacts.

## Security reports

Do not open a public issue for a suspected vulnerability. Follow
[`SECURITY.md`](SECURITY.md) and use the repository's private vulnerability
reporting channel once it is enabled.

## Project maturity

The project is under active development and has not completed U12 whole-system
acceptance. Support is best-effort until the first stable release.
